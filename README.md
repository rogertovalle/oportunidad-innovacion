# Oportunidad, Innovación y Transformación Digital

Una presentación de **Rogert Steven Ovalle Silva** con **Victoriia Studio**.
Leer el entorno, compartir ideas y transformarlas en progreso.

**Verla:** https://rogertovalle.github.io/oportunidad-innovacion/

- **Recorrerla:** desliza; la animación sigue tu ritmo.
- **Presentarla:** botón «Presentar» o `?vista=presentar` · ← → o espacio para avanzar · **F** pantalla completa · **P** cambia de vista.

Sitio estático (HTML, CSS y JavaScript, sin dependencias ni rastreo propio). Las escenas de YouTube se cargan solo al abrirlas (youtube-nocookie) y se ven dentro de la presentación, con un botón para volver. Respeta la preferencia de movimiento reducido.
Fuentes: Fraunces e IBM Plex Sans (SIL Open Font License, ver `fonts/LICENSE.md`).
Las películas citadas (*El origen*, *The Imitation Game / Código Enigma*) se enlazan a YouTube; sus derechos son de sus dueños.
